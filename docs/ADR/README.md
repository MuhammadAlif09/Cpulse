# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for the Cpulse project.

## What is an ADR?

An ADR documents a significant architectural decision along with its context and consequences. They help future contributors understand **why** certain choices were made.

## Format

Each ADR follows this template:

```
# ADR-NNN: Title

## Status
Accepted | Deprecated | Superseded by ADR-NNN

## Context
What is the problem or situation that prompted this decision?

## Decision
What was decided?

## Consequences
What are the trade-offs and implications?
```
